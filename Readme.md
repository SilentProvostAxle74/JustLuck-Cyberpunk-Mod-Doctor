## 🚀 Features

- **Mod Manager** — Browse and organize installed modifications.
- **Conflict Detection** — Identify potential mod compatibility issues.
- **Mod Diagnostics** — Inspect mod installations and dependencies.
- **Backup Management** — Manage mod configuration backups.
- **Modern UI** — Cyberpunk-inspired interface with intuitive navigation.
