# Contributing

Thanks for checking out JustLuck Mod Doctor.

## Right now
We are validating demand for a proposed product. Useful contributions include specific workflows, bug reports for the interface, accessibility feedback, and concrete modding pain points.

## Submitting issues
- State which game version, modding tool, and Windows version you use if relevant.
- Provide reproduction steps without including personal information.
- Don't post copyrighted files, game files, license keys, or private filesystem paths.
- Distinguish feature suggestions from issues with the current UI prototype.

## Pull requests
For code changes, describe what you changed, how you tested it, and attach screenshots for visual changes. Keep demo data explicitly marked as sample data.

## Conduct
Be respectful and constructive. Do not impersonate official game developers or claim unverified functionality.
