# Community feedback — help shape JustLuck

We're exploring a cleaner way to troubleshoot Cyberpunk 2077 mod setups. This repository currently contains a **visual interface prototype**, and we're looking for player input before committing to a functional tool.

## Five quick questions

1. What's your biggest annoyance when modding Cyberpunk 2077?
2. Which tools do you currently use (e.g. Vortex, REDmod, manual installation)?
3. What is missing from those tools for your workflow?
4. Which would you try first: dependency checker, conflict report, loadout backup, or update audit?
5. Would you test a read-only Windows alpha and share its diagnostic report?

Create an issue using the **Feature request** template or start a discussion in a community where sharing projects is permitted. Be transparent that the current build is a prototype. Never upload private paths or personal information in reports.

## Demand-test benchmarks (targets, not forecasts)

- 100 genuine repository visits from relevant communities.
- 15 detailed, independent feedback responses.
- 10 prospective alpha testers.
- At least one consistently reported problem that current tools fail to address.

Avoid artificial stars, fabricated downloads, or claiming a release is functional before it is tested.
